# 原神竖琴自动弹奏

这是一个面向 Windows 的原神竖琴自动弹奏程序。目前包含可视化琴谱编辑器。GUI 播放通过项目自带的 KMDF/VHF 虚拟 HID 键盘驱动输出；原有 `SendInput` 和 STM32 串口实现保留为独立的诊断/兼容后端，不再作为 GUI 的默认输出。

## 目录与职责

```text
include/yuanqin/core/       乐谱领域模型与解析器的公开接口
include/yuanqin/playback/   播放器、键盘/串口输出接口的公开接口
src/core/                   乐谱解析实现（不依赖 Windows）
src/playback/               时间调度与 Windows/串口实现
apps/keyboard_console/      键盘模式的临时控制台入口
apps/serial_console/        串口模式的临时控制台入口
driver/YuanqinVhid/          KMDF/VHF 虚拟键盘驱动工程
shared/                      GUI 与驱动共用的 IOCTL 协议
tests/                      无需游戏或硬件的解析器测试
```

图形界面使用独立的 `ui::ScoreDocument` 维护可编辑内容；播放时可将序列化结果交给 `core::ScoreParser`，再由 `playback::MusicPlayer` 调度，因此编辑、保存/加载和播放逻辑彼此解耦。

## 图形界面

运行 `build/yuanqin_gui.exe` 即可启动“幽歌琴谱”。界面支持：

- 新建空白乐谱，以及同时打开多个乐谱并通过顶部标签切换；
- 从 `sheetMusic/` 加载 `.txt` 乐谱，加载后的修改只存在于内存；
- 保存到原文件或另存为新文件；
- 每行显示 4 个乐谱分区，每个分区包含 4 个最小播放拍位；
- 普通拍位只能输入一个字母音符；输入 `(` 或 `[` 会自动补全，并允许在组内连续输入音符；
- 使用方向键、Tab 在拍位间移动，Backspace 删除组内最后一个音，Delete 清空当前拍位。

界面底部提供音乐播放器式的播放控制：

- 第一个图标从当前编辑位置播放，并在播放时切换为暂停图标；第二个图标始终从乐谱开头播放；
- 点击乐谱拍位会同步进度位置；播放中点击其他拍位会立即从该位置重新播放；
- 拖动进度条可任意定位。播放中拖动会在松开后从新位置继续，暂停时拖动仍保持暂停；
- 播放时锁定乐谱输入，避免模拟按键被误写入编辑器；当前拍位会在编辑区高亮；
- 播放行会尽量保持在编辑区中间。播放时仍可手动滚动，停止滚动 3 秒后自动回到当前播放行；
- `BPM` 输入框用于设置播放速度，播放期间会暂时锁定。
- 窗口会保持在游戏上层，底部的“界面透明度”滑杆可在 25% 到 100% 之间调节整个 UI；
- 播放按钮、进度条、透明度条，以及原神位于前台时的乐谱拍位点击采用“不激活窗口”模式，操作时不会抢走原神的前台焦点；
- 拖动顶部青色区域中的“拖动窗口”提示区可在播放期间移动 UI，拖动过程不激活窗口、不中断向原神输出；
- 开始播放时会自动查找 `YuanShen.exe` / `GenshinImpact.exe` 并将其设为键盘输出目标；未找到游戏时不会向其他窗口误发按键。

常用快捷键为 `Ctrl+N`、`Ctrl+O`、`Ctrl+S`、`Ctrl+Shift+S` 和 `Ctrl+W`。

## 字母乐谱格式

- 高音：`Q W E R T Y U`
- 中音：`A S D F G H J`
- 低音：`Z X C V B N M`
- `/` 结束一个小节；每个小节有 4 个节拍位置。
- 单个字母占一个节拍；空格或 Tab 表示一个休止节拍。
- `(QAZ)` 表示和弦，同时按下括号内音符。
- `[QAZ]` 表示琵琶音，按顺序弹出括号内音符。为兼容旧版本，它占用该位置起的一个小节，建议将其放在小节开头，后面留空。

字母大小写不影响演奏。数字谱和 `+`/`-` 八度标识当前会被忽略，尚未实现转换。

例如：`(AZ)[QW]J /` 表示第一拍弹和弦 `AZ`，第二拍弹琵琶音 `QW`，第三拍弹 `J`，第四拍休止。

## 构建与测试

需要 CMake 和支持 C++20 的 Windows 编译器（仓库当前的 MinGW-w64 可直接使用）：

```powershell
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

生成的 `yuanqin_keyboard.exe` 是旧版 `SendInput` 诊断程序；`yuanqin_serial.exe` 是 115200、8N1 的 STM32 串口模式。串口模式保留了旧版每键 40ms 的保护间隔，避免现有单字节 STM32 固件吞键。

## 虚拟 HID 驱动

GUI 不再调用 `SendInput`。播放时它会查找 `Yuanqin Virtual HID Keyboard` 设备，通过共享 IOCTL 协议提交单音或最多六音的同时按键报告；播放完成、暂停、跳转或发生错误时会发送全键释放。找不到驱动时 GUI 会停止播放并显示安装提示，不会静默回退到旧输入方式。

驱动不会被普通 CMake 构建自动编译。构建、测试签名和开发机安装步骤见 [`driver/README.md`](driver/README.md)。驱动安装完成后，仍建议在原神的窗口化或无边框模式下使用覆盖层。
